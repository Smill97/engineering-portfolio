Miniature C-Arm Fluoroscopy Simulator

A three-axis mechatronic system developed for the Sensors and Actuators course at the University of Western Ontario.

01 / Project overview

Project overview

Designed a 3D-printed C-arm fluoroscopy simulator as a way to provide a portable and cost-effective alternative for medical training and equipment demonstrations. The system replicated three degrees of freedom using stepper motors, rack-and-pinion mechanisms, an Arduino Nano ESP32, accelerometer feedback, and wireless control. The final prototype demonstrated repeatable positioning, preset movements, motion limits, emergency stopping, and real-time control without radiation or full-scale clinical equipment.

The simulator was designed to connect with the same type of digital workflow used by real C-arm systems. The physical model’s accelerometer provides position and orientation data, which can be transmitted to the software to generate corresponding real-time digitally reconstructed radiographs (DRRs). As the user moves the C-arm, the software updates the displayed image to reflect the selected viewing angle and position, such as anteroposterior, lateral, or oblique views.

This creates a link between the mechanical movement of the simulator and the imaging software used to represent clinical procedures. Although the prototype does not produce real X-rays, it reproduces the positioning and visualization process in a safe, portable format. The system could also be integrated with existing medical-imaging or training software through wireless communication, serial data, or an application programming interface (API), allowing the simulator to function as a hardware controller for virtual fluoroscopy environments. This would support realistic training without requiring access to a full-size C-arm, radiation equipment, or a clinical operating room.

02 / Methods

Methods

This section provides an overview of the process used to develop, build, and test the system.

Mechanical component design

The mechanical components were modelled in SolidWorks before being manufactured using 3D printing. Rack-and-pinion mechanisms were used to convert motor rotation into controlled linear movement, while the frame and support components were designed to minimise weight without compromising rigidity. Component clearances, mounting locations, and assembly interfaces were checked in CAD before fabrication. The completed parts were assembled and adjusted to ensure smooth, repeatable movement across all three axes.

Electrical component design

The electrical system was designed around an Arduino Nano ESP32, which controlled the stepper motors, accelerometer,wireless communication, and safety functions. Motor drivers were used to control each axis independently, while limit switches and programmed motion limits helped prevent over-travel. The wiring schematic was developed to organise the motor, sensor, and power connections and to simplify troubleshooting during testing. The accelerometer provided orientation data.

03 / Calculations

Engineering Analysis

To evaluate the motion behaviour of the C-arm simulator, the team developed a simplified mathematical model of the stepper-motor-driven system. The model was used to assess the relationship between system gain, stability, response time, and positioning behaviour. The root-locus plot shows how the system poles change as the control gain varies. This allowed the team to assess system stability and understand the effect of changing the controller gain.The step-response plot was then used to evaluate the system’s response to a commanded movement. The simulated response reached the target position with an approximately 4.5-second settling time and negligible overshoot. This was appropriate for the simulator because smooth and repeatable positioning was more important than maximum movement speed. The analysis also highlighted the limitations of the open-loop stepper-motor approach. Since position was estimated using motor steps, missed steps could cause positional drift. The team identified rotary encoders as a potential future improvement to provide closed-loop feedback and improve positioning accuracy

04 / Software design

Software design

The simulator software was developed using an Arduino Nano ESP32 to control the three stepper-motor-driven axes. The program allowed each axis to be operated independently while controlling its direction and speed.Oporators could have each axis move a linear distance if disired or to predefined positions. Serial communication was used to send movement commands and monitor system data. The software also included preset positions, orientation feedback from the onboard accelerometer, motion limits, and an emergency-stop function. Position data was stored in EEPROM so the system could retain its position after restarting. Together, these features provided controlled, repeatable, and safe operation of the C-arm simulator.

Desired commands

  • Move each axis independently
  • Control direction and speed
  • Read and display orientation feedback
  • Return the system to a known position
  • Stop motion safely
