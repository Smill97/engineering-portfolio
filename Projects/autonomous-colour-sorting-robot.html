Autonomous Colour-Sorting Robot

01 / Project overview

Building an autonomous collection and sorting system

The Autonomous Colour-Sorting Robot was a second-year mechatronics design project focused on developing a self-powered robot capable of navigating an area, collecting coloured objects, sorting them by value, and returning them to a base station within 120 seconds.

The robot was controlled using ESP32-based microcontrollers and designed to operate autonomously within an area of up to 25 m2. The project required the integration of mechanical design, electronics, sensors, programming, and rapid prototyping to create a lightweight, serviceable, and reliable system.

04 / Design and development

The final design used a two-wheel rear-drive system with a central ball support for manoeuvrability. A rotating combine-style header collected objects from the floor as the robot moved. This replaced an earlier robotic-arm concept, reducing the robot's weight, complexity, and number of moving parts.

Collected objects travelled through a funnel and ramp system, allowing them to pass individually beneath a colour sensor. Based on the detected colour, a servo motor directed each object into either the high-value or low-value storage compartment.

05 / Testing and validation

Testing the complete system

The completed robot underwent testing of its main subsystems, including locomotion accuracy and repeatability, ultrasonic sensor performance, base-station detection, colour recognition and sorting accuracy, and overall system integration.

Locomotion testing involved repeatedly following a marked route and reaching designated floor markers. Wheel-speed checks confirmed that inconsistent motor speeds were not the primary cause of drifting. Instead, the positioning and loading of the ball drive were identified as more significant factors.

The colour-sorting system was tested using objects with different colours, sizes, and hues. Sensor readings were monitored through the Arduino IDE serial monitor, allowing the sorting thresholds and code to be adjusted under different lighting conditions.

Measured results
  • 45 sorting trials
  • 90% average overall sorting accuracy
  • 82% average green-object identification accuracy
  • Performance varied under changing lighting conditions
06 / Challenges and problem-solving

Improving navigation, collection, and recognition

The robot initially experienced drifting and inconsistent turns. Physical testing of the wheel speeds, drive configuration, and ball-drive placement showed that repositioning the ball drive improved turning behaviour and path accuracy.

The initial robotic-arm collection concept was rejected because of its weight, complexity, and motor-load requirements. Replacing it with a rotating combine header simplified the design and improved collection efficiency.

Colour recognition was affected by environmental lighting, requiring repeated calibration of sensor thresholds and refinement of the control code. The ultrasonic return-to-base system also highlighted the limitations of relying on a single sensor for navigation.

Design decisions
  • Repositioned the ball drive to improve turning
  • Replaced the robotic arm with a rotating header
  • Calibrated colour thresholds for changing light
  • Identified the need for a multi-sensor return system
07 / Reflection

This project provided practical experience in developing an integrated autonomous system from an initial problem statement through concept selection, prototyping, testing, and evaluation. It demonstrated the importance of considering mechanical, electrical, and software requirements together rather than designing each subsystem in isolation.

A key learning outcome was the value of iterative testing. Issues such as drifting, sensor variation, and object-handling problems were not fully apparent during the initial design stages and were identified through practical trials. Testing therefore informed changes to both the physical design and the control code.

The project also reinforced the importance of designing for reliability and maintainability. The final robot performed effectively, but the identified limitations showed that sensor placement, environmental conditions, wire management, and service access are important factors in developing a robust autonomous machine.
